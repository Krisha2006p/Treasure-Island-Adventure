# 🏝️ Treasure Island Adventure

A simple Python text-based adventure game inspired by *Treasure Island*.  
Make choices to find the treasure — or meet your doom!  
Perfect for beginners learning conditionals and user input in Python.

---

## 🎮 How to Play

1. Clone this repository:
   ```bash
   git clone https://github.com/Krisha2006p/Treasure-Island-Adventure.git

2. Navigate to the repo folder (optional):
   ```bash
   cd Treasure-Island-Adventure

3. Run the game:
   ```bash
   python treasure_island.py
   
---

## 🧠 Concepts Used

Conditional statements (if, elif, else)

User input with input()

Basic ASCII art in Python

Simple game logic and flow control
